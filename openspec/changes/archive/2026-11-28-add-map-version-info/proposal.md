# Proposal

## Why

Users need to identify which version of Mind PKM is running when checking for an update or reporting an issue.

## What Changes

- Add Help → About Mind PKM... to the map window.
- Show the running application's version in a dialog, including on the welcome screen.

## Capabilities

### Modified Capabilities

- `application-shell` gains a Help menu and a version information dialog.

## Impact

The map window and its user documentation gain a new command.
